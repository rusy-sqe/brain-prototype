Surface roles now resolve under [data-theme="dark"] / [data-theme="light"] in addition to the OS media query — apps with their own theme toggle set the attribute on any ancestor instead of re-skinning components.

05 · Tailwind/shadcn token bridge

M&A Brain runs Tailwind + shadcn, themed via HSL-triplet variables and a .dark class — a different convention from this DS's hex tokens and [data-theme] attribute. tokens-shadcn-bridge.css maps this DS's exact colors into shadcn's variable names so shadcn components stay on-brand without a rewrite.

<link rel="stylesheet" href="tokens.css"> <link rel="stylesheet" href="tokens-shadcn-bridge.css"> <html class="dark"> <!-- shadcn's own toggle convention, kept independent of [data-theme] -->
